Common Query Methods:

# Get all records
all_tasks = Task.query.all()

# Get first record
first_task = Task.query.first()

# Filter by field
completed = Task.query.filter_by(completed=True).all()

# Complex filtering
high_priority = Task.query.filter_by(priority='high').all()

# Order by
ordered = Task.query.order_by(Task.created_at.desc()).all()

# Limit results
limited = Task.query.limit(5).all()

# Get by ID (or 404)
task = Task.query.get_or_404(task_id)

# Count
count = Task.query.count()

# Chain methods
tasks = Task.query.filter_by(completed=False)\
                  .order_by(Task.priority)\
                  .limit(10)\
                  .all()

Query Methods Summary:

  • .all() - Get all results as a list
  • .first() - Get first result or None
  • .get(id) - Get by primary key
  • .get_or_404(id) - Get or return 404 error
  • .filter_by() - Simple equality filtering
  • .filter() - Advanced filtering with expressions
  • .order_by() - Sort results
  • .limit(n) - Limit number of results
  • .count() - Count results
