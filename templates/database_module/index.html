🎯 What is ORM?

ORM (Object-Relational Mapping) lets you interact with databases using Python objects instead of writing SQL queries.

❌ Without ORM (Raw SQL)

cursor.execute(
    "INSERT INTO task VALUES (?, ?, ?)",
    (title, description, False)
)
conn.commit()

✅ With ORM (Python)

task = Task(title=title, description=desc)
db.session.add(task)
db.session.commit()

✨ Why Use ORM?

🐍

Write Python, Not SQL

Use familiar Python syntax for database operations

🔒

Prevent SQL Injection

Automatic protection from security vulnerabilities

🔄

Database Agnostic

Switch between SQLite, PostgreSQL, MySQL easily

🧹

Clean & Maintainable

Easier to read, test, and refactor code

🗂️ ORM Model Definition:

# Each class = database table
# Each attribute = table column
class Task(db.Model):
    # Primary key (unique ID for each record)
    id = db.Column(db.Integer, primary_key=True)
    
    # Required text field (max 100 characters)
    title = db.Column(db.String(100), nullable=False)
    
    # Optional text field (unlimited length)
    description = db.Column(db.Text)
    
    # Boolean with default value
    completed = db.Column(db.Boolean, default=False)
    
    # Auto-set timestamp when created
    created_at = db.Column(db.DateTime, default=datetime.utcnow)

📖 What This Creates:

This Python class automatically creates this SQL table:

CREATE TABLE task (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title VARCHAR(100) NOT NULL,
    description TEXT,
    completed BOOLEAN DEFAULT 0,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

🔄 CRUD Operations Quick Reference:

CREATE (Insert)

task = Task(title="Learn ORM")
db.session.add(task)
db.session.commit()

READ (Select)

tasks = Task.query.all()
task = Task.query.get(1)
filtered = Task.query.filter_by(completed=True).all()

UPDATE (Modify)

task = Task.query.get(1)
task.title = "Updated Title"
db.session.commit()

DELETE (Remove)

task = Task.query.get(1)
db.session.delete(task)
db.session.commit()
