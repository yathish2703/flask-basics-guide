📚 Database Operations Explained:

Read All Tasks (SELECT)

# Query all tasks from database
tasks = Task.query.all()

# SQL equivalent: SELECT * FROM task
What it does: Fetches all Task records from database as a list

Toggle Task Status (UPDATE)

# Find task by ID or return 404 error
task = Task.query.get_or_404(task_id)

# Flip the boolean value
task.completed = not task.completed

# Save changes to database
db.session.commit()

# SQL: UPDATE task SET completed=? WHERE id=?
What it does: Changes task.completed from True→False or False→True

Delete Task (DELETE)

# Find the task to delete
task = Task.query.get_or_404(task_id)

# Mark for deletion
db.session.delete(task)

# Execute the deletion
db.session.commit()

# SQL equivalent: DELETE FROM task WHERE id=?
What it does: Permanently removes task record from database
