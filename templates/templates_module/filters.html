Jinja2 Filters

Text Filters

Filter Result
{{ "{{ text }}" }} {{ text }}
{{ "{{ text|upper }}" }} {{ text|upper }}
{{ "{{ text|capitalize }}" }} {{ text|capitalize }}
{{ "{{ text|title }}" }} {{ text|title }}
{{ "{{ text|length }}" }} {{ text|length }}

Number Filters

Filter Result
{{ "{{ number }}" }} {{ number }}
{{ "{{ number|int }}" }} {{ number|int }}
{{ "{{ number|round(2) }}" }} {{ number|round(2) }}

List Filters

Filter Result
{{ "{{ items|length }}" }} {{ items|length }}
{{ "{{ items|first }}" }} {{ items|first }}
{{ "{{ items|last }}" }} {{ items|last }}
{{ "{{ items|join(', ') }}" }} {{ items|join(', ') }}
{{ "{{ items|reverse|list }}" }} {{ items|reverse|list }}

Safety Filters

Raw HTML (dangerous):

{{ "{{ html_text }}" }}: {{ html_text }}

Escaped (safe):

{{ "{{ html_text|e }}" }}: {{ html_text|e }}

Default Filter

{{ "{{ undefined_var|default('No value') }}" }}: {{ undefined_var|default('No value') }}

Common Filters:

  • |upper - Convert to uppercase
  • |lower - Convert to lowercase
  • |title - Title case
  • |length - Get length
  • |default(val) - Default value if undefined
  • |join(sep) - Join list items
  • |safe - Mark as safe HTML (use carefully!)
  • |e or |escape - Escape HTML
