How Template Inheritance Works

This page extends base.html and overrides specific blocks:

Child Template Code:

{% raw %}{% extends "base.html" %}

{% block title %}{{ title }}{% endblock %}

{% block content %}
    <h1>{{ content }}</h1>
{% endblock %}{% endraw %}

Base Template Structure:

{% raw %}<!DOCTYPE html>
<html>
<head>
    <title>{% block title %}Default Title{% endblock %}</title>
</head>
<body>
    <nav>...</nav>
    {% block content %}{% endblock %}
    <footer>...</footer>
</body>
</html>{% endraw %}

Benefits of Template Inheritance:

  • Reuse common layout across multiple pages
  • Maintain consistent navigation and footer
  • Override only the parts that change
  • Keep code DRY (Don't Repeat Yourself)
