🗺️ Understanding Routes

Learn how URLs map to different pages with real-world examples

🤔 What is a Route?

A route is like a map that tells your Flask app what to show when someone visits a specific URL. Think of it like addresses in real life!

🏠 Real World

Address: 123 Main Street
You get: A specific house

🌐 Web World

URL: /about
You get: About page

📝 Simple Route Example

@app.route('/home') def home(): return "Welcome to my website!"

What this means:

  • ✅ When someone visits /home
  • ✅ Flask runs the home() function
  • ✅ Returns "Welcome to my website!" to the browser

⚡ Dynamic Routes (URL Parameters)

Dynamic routes let you capture parts of the URL and use them as variables. It's like having a template!

@app.route('/user/<username>') def show_user(username): return f"Hello, {username}!"

/user/john

→ "Hello, john!"

/user/mary

→ "Hello, mary!"

/user/alex

→ "Hello, alex!"

🌍 Real-World Hierarchy Example

Let's build a location system: India → State → City → Area → Company
Example: Karnataka (State) → Bengaluru (City) → Whitefield (Area) → Infosys (Company)

📍 Level 1: State

@app.route('/india/<state>') def state_info(state): return f"Information about {state}"
Try: /india/karnataka

🏙️ Level 2: State → City

@app.route('/india/<state>/<city>') def city_info(state, city): return f"{city} in {state}"
Try: /india/karnataka/bengaluru

🗺️ Level 3: State → City → Area

@app.route('/india/<state>/<city>/<area>') def area_info(state, city, area): return f"{area} area in {city}, {state}"
Try: /india/karnataka/bengaluru/whitefield

🏭 Level 4: State → City → Area → Company

@app.route('/india/<state>/<city>/<area>/<factory>') def factory_info(state, city, area, factory): return f"{factory} company details"
Try: /india/karnataka/bengaluru/whitefield/infosys

🔑 Key Concepts

📦 URL Parameters

Captured with <variable>

/user/<username>
/post/<post_id>

🎯 Multiple Parameters

Use multiple variables in one route

/country/<state>/<city>
/blog/<year>/<month>/<title>

🔢 Type Converters

Specify parameter types

/user/<int:user_id>
/price/<float:amount>
/path/<path:filepath>

🔄 URL Building

Generate URLs dynamically

url_for('state_info',
        state='california')
