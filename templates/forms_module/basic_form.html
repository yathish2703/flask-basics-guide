📝 HTML Form Structure:

<form method="POST">  <!-- Send data via POST request -->
    <!-- 'name' attribute is the key to access data -->
    <input type="text" name="name" required>
    <input type="email" name="email" required>
    <textarea name="message"></textarea>
    <button type="submit">Submit</button>
</form>

method="POST": Sends form data in request body (secure for passwords)

name attribute: Used to identify each field (like a variable name)

🐍 Flask Form Handling:

# Accept both GET (show form) and POST (submit form)
@app.route('/form', methods=['GET', 'POST'])
def form():
    # Check if form was submitted
    if request.method == 'POST':
        # Get data using the 'name' from HTML input
        name = request.form.get('name')
        email = request.form.get('email')
        message = request.form.get('message')
        
        # Process data (save to DB, send email, etc.)
        # ...
        
    # Show the form (GET request)
    return render_template('form.html')

GET request: Display the form to user

POST request: User submitted form, process the data

request.form.get(): Safely retrieve form data by name

Flow: User fills form → clicks submit → POST request → process data
