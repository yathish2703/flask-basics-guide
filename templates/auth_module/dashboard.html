🔒 How Protected Routes Work:

This page uses the @login_required decorator. Users must be logged in to access it.

# Import authentication decorators
from flask_login import login_required, current_user

# Define the route
@app.route('/dashboard')
# Protect it - only logged-in users can access
@login_required
def dashboard():
    # Access logged-in user data with current_user
    username = current_user.username
    # Render template with user data
    return render_template('dashboard.html')

@login_required: Decorator that checks if user is logged in

current_user: Special object that contains logged-in user's data

Behavior: If not logged in → redirects to login page

Benefit: Protects sensitive pages from unauthorized access
