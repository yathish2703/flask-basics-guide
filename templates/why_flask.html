🚦 Routing Made Easy

Map URLs to Python functions with simple decorators!

@app.route('/hello')
def hello():
    return "Hello, Flask!"

@app.route('/user/<name>')
def greet_user(name):
    return f"Hello, {name}!"

Try it: Visit /user/John → Returns "Hello, John!"

📄 Dynamic Templates with Jinja2

Render HTML with Python variables - no string concatenation!

Python Code:

@app.route('/')
def home():
    user = {
        'name': 'Alice',
        'age': 25
    }
    return render_template(
        'home.html', 
        user=user
    )

🗄️ Database Magic with SQLAlchemy ORM

Write Python classes instead of SQL queries!

# Define your model
class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True)
    email = db.Column(db.String(120), unique=True)

# Create a new user
new_user = User(username='alice', email='alice@example.com')
db.session.add(new_user)
db.session.commit()

# Query users
all_users = User.query.all()
alice = User.query.filter_by(username='alice').first()

No SQL needed! Flask translates Python to SQL automatically! ✨

🌐 Build REST APIs in Minutes

Return JSON data for frontend apps or mobile apps!

@app.route('/api/users')
def get_users():
    users = User.query.all()
    return {
        'users': [
            {'id': u.id, 'name': u.username}
            for u in users
        ]
    }

@app.route('/api/user/<int:id>')
def get_user(id):
    user = User.query.get_or_404(id)
    return {
        'id': user.id,
        'username': user.username,
        'email': user.email
    }

Response: {"id": 1, "username": "alice", "email": "alice@example.com"}
