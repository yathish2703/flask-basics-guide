📝 Simple Route Code:

# Import Flask to create web app
from flask import Flask
app = Flask(__name__)

# @app.route() decorator maps URL to function
@app.route('/hello')
def hello():
    # Return HTML to display in browser
    return '<h1>Hello, Flask!</h1>'

# When user visits /hello, this function runs

@app.route('/hello'): Decorator that registers the URL path

def hello(): Function that runs when URL is visited

return: HTML content sent to user's browser

Result: Visit /hello → see "Hello, Flask!" heading
