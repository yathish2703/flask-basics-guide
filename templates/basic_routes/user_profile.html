🎯 URL Parameter

This route uses a URL parameter: <username>

Try changing the URL to see different names. For example:

/basic/user/Alice /basic/user/Bob /basic/user/Charlie

📝 Code Example:

@app.route('/user/<username>')  # Define route with parameter
def user_profile(username):        # username is passed as argument
    return f'Hello, {username}!'   # Use the parameter in response

Line 1: <username> defines a dynamic part of the URL

Line 2: The function receives username as a parameter

Line 3: You can use the parameter value in your response

💡 How It Works

URL Pattern: /user/<username>

Example URL: /user/{{ username }}

Captured Value: username = "{{ username }}"

The <username> in the route captures whatever text appears in that position of the URL and passes it as an argument to your function.
