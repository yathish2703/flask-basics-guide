📝 HTTP Methods Code:

# Allow multiple HTTP methods for this route
@app.route('/methods-demo', methods=['GET', 'POST', 'PUT', 'DELETE'])
def methods_demo():
    # Get the HTTP method used
    method = request.method
    
    # Different logic for each method
    if method == 'GET':
        return 'Reading data'
    elif method == 'POST':
        return 'Creating new data'
    elif method == 'PUT':
        return 'Updating data'
    elif method == 'DELETE':
        return 'Deleting data'

methods=[]: List of allowed HTTP methods for this route

request.method: Returns which method was used (GET, POST, etc.)

Default: If methods not specified, only GET is allowed

💡 HTTP Methods Explained

GET

Retrieve data from the server (default method for browser navigation)

POST

Send data to create a new resource (e.g., form submissions)

PUT

Update an existing resource completely

DELETE

Remove a resource from the server

PATCH

Partially update an existing resource
