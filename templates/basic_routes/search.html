📝 Code Example:

# Import request object to access query parameters
from flask import request

@app.route('/search')
def search():
    # Get 'q' parameter, default to 'nothing' if not provided
    query = request.args.get('q', 'nothing')
    
    # Get 'category' parameter with default value
    category = request.args.get('category', 'all')
    
    # Get 'page', convert to int (default 1)
    page = request.args.get('page', 1, type=int)
    
    # Get all parameters as dictionary
    all_params = dict(request.args)
    
    return render_template('search.html', 
                         query=query,
                         category=category,
                         page=page,
                         all_params=all_params)

request.args: Contains all query string parameters

.get('key', default): Safely get parameter with fallback value

type=int: Automatically converts string to integer

dict(request.args): Convert to regular Python dictionary

💡 URL vs Query Parameters

URL Parameters (Path Variables)

/user/<username>
  • Part of the URL path structure
  • Required for route to match
  • Example: /user/john
  • Best for: identifying specific resources

Query Parameters (Query String)

?q=value&page=1
  • Optional key-value pairs after ?
  • Not required - can have defaults
  • Example: ?search=flask&sort=date
  • Best for: filtering, sorting, pagination
